# Tapan CSC — Services Website

A responsive, single-page information website for local digital services, built with plain HTML, CSS and JavaScript.

## What's included
- A redesigned responsive layout with a modern green palette, polished cards, hover states and mobile navigation
- Four services: printing & photocopy, online form assistance, bill payment support, and document scanning
- Four interactive local demos:
  - Print estimate calculator using clearly marked sample rates
  - Sample document checklist for common form categories
  - Bill summary preview that does not make a payment
  - Local PDF/image details and preview; the file is not uploaded
- Your store address and a Google Maps directions search
- Automatically updated footer year

## Run the website
1. Download and extract the project ZIP.
2. Open the `tapan_csc_website` folder.
3. Double-click `index.html` to open it in a modern browser, or open the folder in VS Code and use Live Server.
4. Select **Try demo** on any service card to explore its demo.

No Node.js or package installation is required.

## Customize
- Edit text and service details in `index.html`.
- Update colors, typography and layout in `style.css`.
- Update the interactive demonstrations in `script.js`.

## Important notes
This is an independent demo website, not an official government portal. Sample prices and checklists are for demonstration only. The demos do not submit government applications, make bill payments, upload files, collect payments, or store customer requests. Avoid entering sensitive personal or payment information into demo fields. Confirm service availability, official requirements and fees with the relevant authorised service operator.
